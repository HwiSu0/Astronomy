하이탑 지구과학Ⅱ ‘행성의 운동’ · 천문 올림피아드 심화

하늘을 보면 천구가 보이도록

천구의 구성 요소와 지평·적도·황도·은하 좌표계를 3D로 직접 돌려 보고, 위도와 시각을 바꾸며 일주 운동을 관찰하고, 내행성·외행성의 운동을 실제 날짜로 시뮬레이션합니다. 교과서의 기본 개념부터 올림피아드 수준의 계산까지 한곳에서 연습할 수 있습니다.

학습 가이드로 시작하기 적경·적위 훈련
01 — 3D 실험실

천구와 좌표계

3D 천구에서 지평·적도·황도·은하 좌표계를 겹쳐 보고, 별을 클릭해 고도·방위각·적경·적위·시간각을 호(arc)로 확인합니다. 위도·날짜·시각을 바꾸면 일주 운동 궤적이 그려집니다.

15단계 학습 가이드 · 관측자 시점 · 일주 궤적 · 천문 삼각형 · 세차 운동
 02 — 2D 실험실

행성의 운동

내합·외합·최대 이각, 충·합·구를 실제 궤도(JPL 궤도 요소)로 계산합니다. 시선이 별자리 띠에 그리는 겉보기 위치로 순행·역행·유를 이해하고, 금성의 위상 변화를 확인합니다.

역행 원리 그림 · 지구 중심 궤적 · 다가오는 현상 날짜 · 회합 주기
 03 — 2D 실험실

달의 운동

실제 날짜의 달 위상, 서울의 월출·남중·월몰 시각, 항성월과 삭망월의 차이, 백도와 교점, 앞으로 일어날 일식·월식(서울 관측 가능 여부)을 계산합니다.

위상과 뜨는 시각 · 항성월·삭망월 · 일식·월식 목록 · 사로스·식년
 04 — 2D 실험실

케플러 법칙

이심률과 긴반지름을 바꾸며 면적 속도 일정 법칙을 확인하고, 평균·이심·진근점 이각과 활력 방정식으로 속력을 계산합니다.

케플러 방정식 · 활력 방정식 · 조화 법칙 그래프
 05 — 훈련

적경·적위 훈련

무작위 밤하늘에서 주어진 적경·적위를 찾아 클릭하고, 표시된 별의 좌표를 읽어 냅니다. 값이 매번 바뀌는 계산 문제(기본·심화)와 개념 퀴즈도 있습니다.

하늘에서 찾기 · 좌표 읽기 · 계산 문제 33종 · 개념 퀴즈
 06 — 읽기

개념 노트

천구 → 좌표계 → 일주·연주 운동 → 행성의 운동 → 달의 운동 → 실전 관측 순서로 정리한 노트. 구면 삼각법, 좌표 변환 행렬, 유의 조건, 케플러 방정식 등 심화 내용을 포함합니다.

기본 + 심화 · 예제와 풀이 · 밝은 별 목록

추천 학습 순서

  1. 천구의 구성 요소가이드 1~3단계: 천정, 지평선, 천구의 극, 자오선. 위도를 바꾸며 hP = φ 확인
  2. 좌표계 익히기가이드 4~6, 11~12단계: 지평·적도·황도·은하 좌표계와 시간각·항성시
  3. 일주·연주 운동가이드 7~10단계: 방향별·위도별 일주 운동, 태양의 연주 운동, 항성일
  4. 행성의 운동행성 실험실: 금성(내행성)과 화성(외행성)의 위치 관계, 역행, 회합 주기
  5. 달의 운동가이드 16단계와 달 실험실: 위상과 월출 시각, 삭망월, 백도와 일식·월식
  6. 심화천문 삼각형, 세차 운동, 케플러 방정식, 개념 노트의 보라색 상자
  7. 실전 훈련좌표 찾기·읽기 훈련으로 실제 하늘에서 적경·적위를 쓰는 감각 익히기

사용 팁

조작

천구 모형: 끌어서 회전, 휠로 확대 · 관측자 시점: 끌어서 둘러보기, 휠로 시야 조절 · Space 재생/정지, ←→ 10분 이동(Shift 1시간)

좌표 읽기

빈 하늘 위에 마우스를 올리면 그 지점의 고도·방위각·적경·적위·시간각(그리고 켜 둔 황도·은하 좌표)이 왼쪽 아래에 표시됩니다.

기기

PC와 태블릿 브라우저(크롬, 엣지, 사파리)에서 동작합니다. 3D 화면은 WebGL을 사용하므로 그래픽 가속이 켜져 있어야 합니다.

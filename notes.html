천문학 개념 노트

하이탑 지구과학Ⅱ ‘행성의 운동’ 단원(천체의 좌표계, 행성의 겉보기 운동, 케플러 법칙)의 핵심을 기본으로 정리하고, 천문 올림피아드에서 필요한 심화 내용을 보라색 상자로 덧붙였다. 각 절의 🔬 실험 링크를 누르면 해당 개념을 시뮬레이션에서 바로 확인할 수 있다.

Ⅰ. 천구

1. 천구와 기본 요소

별까지의 거리는 매우 멀어서 맨눈으로는 방향만 알 수 있다. 관측자를 중심으로 하는 반지름이 무한히 큰 가상의 구를 천구라 하고, 모든 천체가 그 표면에 붙어 있다고 생각한다. 천구 위에서는 거리가 의미가 없으므로 두 천체 사이의 거리는 각거리(대원 호의 중심각)로 나타낸다.

  • 대원: 천구의 중심을 지나는 평면과 천구가 만나서 생기는 원 (지평선, 천구의 적도, 자오선, 황도). 소원: 중심을 지나지 않는 평면이 만드는 원 (일주권, 적위선).
구성 요소정의
천정(Z) · 천저(Z′)관측자의 연직선이 천구와 만나는 위쪽 점 · 아래쪽 점
지평선관측자의 지평면이 천구와 만나는 대원 (천정에서 90°)
천구 북극(P) · 남극(P′)지구 자전축을 연장하여 천구와 만나는 점
천구의 적도지구의 적도면을 연장하여 천구와 만나는 대원 (천구의 극에서 90°)
수직권천정과 천저를 지나는 대원 (지평선에 수직)
자오선천정, 천구 북극, 천저, 천구 남극을 지나는 수직권. 지평선과 북점·남점에서 만난다.
묘유선천정과 동점·서점을 지나는 수직권 (자오선에 수직)
시간권천구 북극·남극과 천체를 지나는 대원 (천구의 적도에 수직)
일주권천체가 일주 운동하며 그리는 소원 (천구의 적도와 나란함)

2. 천구의 극과 위도

핵심천구 북극의 고도 $h_P$ = 관측자의 위도 $\varphi$  ·  천구의 적도가 자오선과 만나는 점(남쪽)의 고도 = $90^\circ-\varphi$

위도에 따라 천구의 모습이 달라진다: 북극(φ = 90°)에서는 천구 북극이 천정에 있고 천구의 적도 = 지평선, 적도(φ = 0°)에서는 천구의 극이 북점·남점에 있고 천구의 적도가 천정을 지난다. 남반구(φ < 0)에서는 천구 남극이 지평선 위 |φ|의 고도에 있다.

Ⅱ. 천체의 좌표계

1. 지평좌표계

  • 고도 h: 지평선에서 천체까지 수직권을 따라 잰 각 (−90° ~ +90°). 천정 거리 $z = 90^\circ - h$
  • 방위각 A: 북점에서 지평선을 따라 시계 방향(북 → 동 → 남 → 서)으로 천체의 수직권까지 잰 각 (0° ~ 360°)

관측자 기준이라 쓰기 쉽지만 관측 장소·시각에 따라 같은 천체의 좌표가 계속 변한다. 망원경의 경위대식 가대가 이 좌표계를 쓴다.

주의천문학 고전 교재(예: Smart)나 일부 문제는 방위각을 남점 기준 서쪽으로 잰다. 북점 기준 A와 남점 기준 A′은 $A' = A - 180^\circ$ 관계. 문제의 정의를 반드시 확인하자.

2. 적도좌표계

  • 적위 δ: 천구의 적도에서 시간권을 따라 천체까지 잰 각 (북 +, 남 −). 천구 북극의 적위 = +90°
  • 적경 α: 춘분점에서 천구의 적도를 따라 동쪽(시계 반대 방향)으로 천체의 시간권까지 잰 각. 0h ~ 24h
  • 춘분점(γ): 황도와 천구의 적도의 교점 중 태양이 남쪽에서 북쪽으로 지나는 점 (적경 0h, 적위 0°)
단위 변환$1^h = 15^\circ$, $1^m = 15'$, $1^s = 15''$  ·  $1^\circ = 4^m$, $1' = 4^s$
적위 δ인 곳에서 적경 $\Delta\alpha$ 차이는 실제 각거리로 약 $15^\circ \times \Delta\alpha^h \times \cos\delta$ (적위가 높을수록 일주권이 작아진다)

적경·적위는 천구에 고정되어 일주 운동과 함께 돌기 때문에 관측 장소와 시각에 무관하다. 그래서 성표와 천체 목록은 적도좌표를 쓴다. 다만 세차 운동으로 기준점이 천천히 움직이므로 기준 분점(J2000.0 등)을 함께 적는다.

🔬 실험: 적경과 적위

3. 시간각과 항성시

  • 시간각 H: 자오선에서 천구의 적도를 따라 서쪽으로 천체의 시간권까지 잰 각 (0h ~ 24h). 1시간(항성시)에 1h씩 일정하게 증가
  • 항성시 LST: 춘분점의 시간각
$$H = \text{LST} - \alpha \qquad (\text{남중: } H = 0 \;\Rightarrow\; \text{LST} = \alpha)$$
예제항성시가 3h 00m일 때 베텔게우스(α = 5h 55m)의 시간각과 남중까지 남은 시간은?
풀이$H = 3^h00^m - 5^h55^m = -2^h55^m \;(=21^h05^m)$. 자오선의 동쪽에 있고 항성시로 2h 55m 뒤 남중한다(태양시로는 ×0.99727 → 약 2h 54.5m).
🔬 실험: 시간각과 항성시

4. 황도좌표계

  • 황도: 태양의 연주 운동 경로. 천구의 적도와 $\varepsilon \approx 23.44^\circ$ 기울어짐(황도 경사)
  • 황경 λ: 춘분점에서 황도를 따라 동쪽으로 0° ~ 360° · 황위 β: 황도에서 남북으로 −90° ~ +90°
  • 황도 북극: 용자리 (α = 18h, δ = +66.56°)

태양은 늘 β = 0, 행성·달은 황도 근처에 있어 태양계 천체를 다룰 때 편리하다. 춘분 λ☉ = 0°, 하지 90°, 추분 180°, 동지 270°.

🔭 심화: 적도 ↔ 황도 변환 춘분점 방향(x축)을 축으로 ε만큼 회전한 관계이다. $$\sin\beta = \sin\delta\cos\varepsilon - \cos\delta\sin\varepsilon\sin\alpha,\qquad \tan\lambda = \frac{\sin\alpha\cos\varepsilon + \tan\delta\sin\varepsilon}{\cos\alpha}$$ $$\sin\delta = \sin\beta\cos\varepsilon + \cos\beta\sin\varepsilon\sin\lambda,\qquad \tan\alpha = \frac{\sin\lambda\cos\varepsilon - \tan\beta\sin\varepsilon}{\cos\lambda}$$ 태양(β = 0): $\sin\delta_\odot = \sin\varepsilon\sin\lambda_\odot$, $\tan\alpha_\odot = \cos\varepsilon\tan\lambda_\odot$ (α와 λ는 같은 사분면).
🔬 실험: 황도좌표계

5. 은하좌표계

  • 은하 적도: 우리은하 원반면이 천구와 만나는 대원 (은하수의 중심선)
  • 은경 l: 은하 중심(궁수자리, α = 17h 45.6m, δ = −28.94°)에서 은하 적도를 따라 동쪽으로 0° ~ 360°
  • 은위 b: 은하면에서 남북으로 −90° ~ +90°
  • 은하 북극: 머리털자리 (α = 12h 51.4m, δ = +27.13°) → 은하면과 천구의 적도의 경사 = 90° − 27.13° ≈ 62.87°
🔭 심화: 적도 → 은하 변환 은하 북극 $(\alpha_G, \delta_G) = (192.859^\circ, +27.128^\circ)$, 천구 북극의 은경 $l_{\rm NCP} = 122.932^\circ$일 때 (J2000) $$\sin b = \sin\delta\sin\delta_G + \cos\delta\cos\delta_G\cos(\alpha-\alpha_G)$$ $$\cos b\,\sin(l_{\rm NCP}-l) = \cos\delta\,\sin(\alpha-\alpha_G)$$ $$\cos b\,\cos(l_{\rm NCP}-l) = \sin\delta\cos\delta_G - \cos\delta\sin\delta_G\cos(\alpha-\alpha_G)$$ 실제 계산에서는 J2000 적도 직교 좌표에 고정된 3×3 회전 행렬을 곱한다(이 프로그램도 그렇게 계산한다).

7. 구면 삼각법과 천문 삼각형 심화

구면 삼각형은 세 대원 호로 둘러싸인 도형이며, 변의 길이도 각(중심각)으로 잰다. 변 a, b, c와 각각 마주 보는 각 A, B, C에 대해

$$\text{코사인 법칙: }\cos a = \cos b\cos c + \sin b\sin c\cos A$$ $$\text{사인 법칙: }\frac{\sin A}{\sin a} = \frac{\sin B}{\sin b} = \frac{\sin C}{\sin c}$$ $$\text{사인-코사인 공식: }\sin a\cos B = \cos b\sin c - \sin b\cos c\cos A$$

천문 삼각형 PZX — 천구 북극 P, 천정 Z, 천체 X:

변크기마주 보는 각
PZ$90^\circ-\varphi$ (여위도)∠X = 시차각 q
PX$90^\circ-\delta$ (극거리)∠Z = A (천체가 서쪽이면 $360^\circ - A$)
ZX$90^\circ-h = z$ (천정 거리)∠P = H (천체가 동쪽이면 $360^\circ - H$)

변 ZX에 코사인 법칙, 사인 법칙, 사인-코사인 공식을 적용하면 적도 → 지평 변환을 얻는다.

$$\sin h = \sin\varphi\sin\delta + \cos\varphi\cos\delta\cos H$$ $$\cos h\sin A = -\cos\delta\sin H,\qquad \cos h\cos A = \cos\varphi\sin\delta - \sin\varphi\cos\delta\cos H$$

반대로 지평 → 적도 변환은 φ와 h, δ와 A, H의 역할을 바꾼 꼴이다.

$$\sin\delta = \sin\varphi\sin h + \cos\varphi\cos h\cos A,\qquad \cos\delta\sin H = -\cos h\sin A$$
🔭 자주 쓰는 결과
  • 남중(H = 0): $h = 90^\circ - |\varphi-\delta|$ · 하방 정중(H = 12h): $h = |\varphi+\delta| - 90^\circ$
  • 출몰(h = 0): $\cos H_0 = -\tan\varphi\tan\delta$,  $\cos A = \sin\delta/\cos\varphi$
  • 대기차·태양 반지름을 고려한 출몰(h₀ = −50′): $\cos H_0 = \dfrac{\sin h_0 - \sin\varphi\sin\delta}{\cos\varphi\cos\delta}$
  • 묘유선 통과(A = 90°, 270°): $\sin h = \sin\delta/\sin\varphi$, $\cos H = \tan\delta/\tan\varphi$ (0 < δ < φ)
  • 주극성의 최대 방위(최대 이각, q = 90°): $\sin A_{\max} = \cos\delta/\cos\varphi$, $\cos H = \tan\varphi/\tan\delta$
  • 시차각: $\tan q = \dfrac{\sin H}{\tan\varphi\cos\delta - \sin\delta\cos H}$
  • 두 천체 사이의 각거리: $\cos\theta = \sin\delta_1\sin\delta_2 + \cos\delta_1\cos\delta_2\cos(\alpha_1-\alpha_2)$
🔭 벡터·회전 행렬로 보기 단위 벡터로 쓰면 좌표 변환은 모두 회전이다. 시간각 좌표의 벡터 $\mathbf{u}' = (\cos\delta\cos H,\, -\cos\delta\sin H,\, \sin\delta)$ (x′: 남쪽 자오선 위 적도점, y′: 동점, z′: 천구 북극)와 지평 좌표의 벡터 $\mathbf{u} = (\cos h\cos A,\, \cos h\sin A,\, \sin h)$ (x: 북점, y: 동점, z: 천정) 사이에는 $$\mathbf{u} = \begin{pmatrix} -\sin\varphi & 0 & \cos\varphi \\ 0 & 1 & 0 \\ \cos\varphi & 0 & \sin\varphi \end{pmatrix}\mathbf{u}'$$ 가 성립한다. 성분을 비교하면 위의 세 식이 바로 나온다. 적도 → 황도는 x축 둘레로 ε 회전, 시간각 → 적경은 z축 둘레로 LST 회전이다.
예제 (올림피아드형)서울(φ = 37.5°)에서 시리우스(δ = −16.7°)가 뜨는 방위각과, 떠 있는 시간을 구하라(대기차 무시).
풀이$\cos A = \sin(-16.7^\circ)/\cos 37.5^\circ = -0.2874/0.7934 = -0.3622 \Rightarrow A = 111.2^\circ$ (정동쪽에서 남쪽으로 21.2°).
$\cos H_0 = -\tan 37.5^\circ\tan(-16.7^\circ) = 0.7673\times0.3000 = 0.2302 \Rightarrow H_0 = 76.7^\circ = 5^h07^m$
떠 있는 시간 = $2H_0 = 10^h14^m$ (항성시) ≈ 10h 12m (태양시).

Ⅲ. 일주 운동과 연주 운동

1. 일주 운동

지구가 서→동으로 자전하므로 천구 전체가 천구의 극을 축으로 동→서로 하루 한 바퀴(1시간에 약 15°) 도는 것처럼 보인다. 천체는 천구의 적도와 나란한 일주권을 그린다.

방향 (북반구 중위도)별의 움직임
북쪽 하늘천구 북극(북극성)을 중심으로 시계 반대 방향 원운동
동쪽 하늘지평선에 대해 (90° − φ) 기울어져 오른쪽 위로 떠오름
남쪽 하늘왼쪽(동)에서 오른쪽(서)으로 지평선과 나란한 호
서쪽 하늘오른쪽 아래로 비스듬히 짐
위도천구의 적도와 지평선일주권특징
극 (90°)일치지평선과 나란함뜨고 지는 별 없음, 반구만 보임
중위도(90° − φ) 기울어짐지평선과 비스듬함주극성·출몰성·전몰성
적도 (0°)수직지평선에 수직모든 별이 12시간씩 떠 있음, 전천을 볼 수 있음
🔬 실험: 일주 운동🔬 실험: 위도에 따른 일주 운동

2. 남중 고도와 주극성

$$h_{\text{남중}} = 90^\circ - |\varphi - \delta|,\qquad h_{\text{하방 정중}} = |\varphi + \delta| - 90^\circ$$
  • 주극성(항상 지평선 위): 북반구에서 $\delta \ge 90^\circ - \varphi$
  • 전몰성(항상 지평선 아래): $\delta \le -(90^\circ - \varphi)$
  • 출몰성: 그 사이. δ > 0이면 12시간보다 오래 떠 있고, 정동쪽보다 북쪽에서 뜬다.
예제북쪽 하늘에서 관측한 어떤 주극성의 하루 중 최고 고도가 70°, 최저 고도가 20°였다. 이 지역의 위도와 별의 적위는?
풀이별은 천구 북극을 중심으로 원을 그리므로 천구 북극은 두 고도의 한가운데: $\varphi = h_P = (70^\circ + 20^\circ)/2 = 45^\circ$.
별의 극거리 = $(70^\circ - 20^\circ)/2 = 25^\circ$ → $\delta = 90^\circ - 25^\circ = 65^\circ$.
검산: 남중 고도 $90^\circ - |45^\circ - 65^\circ| = 70^\circ$ (천정의 북쪽), 하방 정중 고도 $|45^\circ + 65^\circ| - 90^\circ = 20^\circ$.

3. 태양의 연주 운동과 계절

지구 공전 때문에 태양은 별을 배경으로 황도를 따라 하루 약 1°씩 서→동으로 움직인다. 태양의 적위가 −23.4° ~ +23.4° 사이에서 변하므로 계절에 따라 남중 고도, 낮의 길이, 출몰 방위가 달라진다.

4. 항성일과 태양일, 별의 연주 운동

지구가 자전하는 동안 공전 궤도를 따라 약 1° 이동하므로, 태양이 다시 남중하려면 약 361° 돌아야 한다.

$$\frac{1}{T_{\text{항성일}}} = \frac{1}{T_{\text{태양일}}} + \frac{1}{T_{\text{년}}} \;\Rightarrow\; T_{\text{항성일}} = 23^h56^m04.1^s$$
  • 같은 별은 매일 약 3분 56초씩 일찍 뜨고 일찍 남중한다 → 한 달에 약 2시간.
  • 같은 시각에 보면 별자리는 하루 약 1°씩 서쪽으로 이동 → 계절마다 보이는 별자리가 다르다.
  • 자정에 남중하는 별의 적경 ≈ 태양의 적경 + 12h. (예: 12월 하순 자정에는 α ≈ 6h인 오리온자리 부근이 남중)
🔬 실험: 같은 시각, 매일 달라지는 하늘

5. 시간 체계 심화

  • 시태양시 = 태양의 시간각 + 12h. 해시계의 시간. 하루의 길이가 1년 동안 조금씩 변한다.
  • 평균 태양시: 천구의 적도를 따라 일정한 속도로 움직이는 가상의 ‘평균 태양’ 기준
  • 균시차 = 시태양시 − 평균 태양시. 원인: ① 공전 궤도의 이심률(황경 증가 속도가 변함) ② 황도 경사(같은 황경 변화도 적경 변화가 다름). 범위 약 −14분(2월 중순) ~ +16분(11월 초). 같은 시각에 태양 위치를 1년간 찍으면 8자 모양의 아날렘마가 생긴다.

  • 율리우스일 JD: 기원전 4713년 1월 1일 정오부터 센 날수. J2000.0 = JD 2451545.0 (2000년 1월 1일 12h TT)

  • 박명: 해가 진 뒤에도 하늘이 밝은 시간. 시민 박명(태양 고도 −6°까지), 항해 박명(−12°), 천문 박명(−18°).

  • 광행차: 지구의 공전 속도 때문에 별빛의 방향이 기울어 보임. 최대 약 20.5″ (v/c)
  • 연주 시차: 지구 공전에 따른 가까운 별의 위치 변화. $d(\text{pc}) = 1/p('')$. 가장 큰 프록시마 센타우리도 0.77″
  • 고유 운동: 별 자체의 운동으로 인한 위치 변화 (바너드 별 약 10.4″/년)

Ⅳ. 행성의 운동

1. 행성의 겉보기 운동

  • 순행: 별자리를 배경으로 서 → 동 이동 (황경 증가) — 대부분의 기간
  • 역행: 동 → 서 이동 (황경 감소) — 외행성은 충 무렵, 내행성은 내합 무렵
  • 유(留): 순행과 역행이 바뀌는 순간 멈춘 것처럼 보이는 상태

태양중심설에서는 역행을 ‘추월’로 자연스럽게 설명한다. 더 빠른 지구가 외행성을 앞지르는 동안(충 부근) 지구에서 본 행성의 시선 방향이 뒤로 돌아간다. 행성 궤도면이 황도면과 조금 기울어져 있어 실제 하늘에서는 역행 경로가 고리(loop)나 지그재그 모양이 된다.

4. 우주관의 변화

  • 프톨레마이오스(지구중심설): 행성이 주전원 위를 돌고 주전원의 중심이 이심원을 따라 지구 둘레를 돈다. 역행을 주전원으로 설명. 금성·수성의 주전원 중심은 항상 지구–태양을 잇는 선 위에 있다 → 금성은 항상 태양보다 가까워 보름달 모양을 보일 수 없다.
  • 코페르니쿠스(태양중심설): 역행을 지구의 추월로 설명, 내행성의 최대 이각과 회합 주기로 행성까지의 상대 거리를 처음으로 계산. 원 궤도를 고집해 여전히 작은 주전원이 필요했다.
  • 티코 브라헤: 행성은 태양 둘레를, 태양은 지구 둘레를 도는 절충 모형. 연주 시차를 관측하지 못해 지구 공전을 받아들이지 않았지만, 그의 정밀한 관측 자료가 케플러 법칙의 바탕이 되었다.
  • 갈릴레이: 망원경으로 금성의 보름달 모양 위상과 크기 변화, 목성의 위성 관측 → 태양중심설 지지
  • 케플러: 화성 관측 자료로 타원 궤도 발견 · 뉴턴: 만유인력으로 케플러 법칙을 설명

5. 케플러 법칙

  1. 타원 궤도: 태양은 타원의 한 초점에 있다. 근일점 거리 $q = a(1-e)$, 원일점 거리 $Q = a(1+e)$
  2. 면적 속도 일정: 같은 시간 동안 쓸고 가는 넓이가 같다 (각운동량 보존) → $v_q/v_Q = Q/q = (1+e)/(1-e)$
  3. 조화 법칙: $P^2 = a^3$ (P: 년, a: AU) · 뉴턴의 일반형 $P^2 = \dfrac{4\pi^2 a^3}{G(M+m)}$
🔬 실험: 케플러 법칙

6. 행성 운동의 정량적 분석 심화

(1) 행성까지의 거리 — 코페르니쿠스의 방법

내행성: 최대 이각일 때 ∠태양–행성–지구 = 90° → $a = \sin E_{\max}$ (AU). 금성 46.3° → 0.723 AU, 이때 지구–금성 거리 = $\cos E_{\max}$.
외행성: 충에서 구까지 걸린 시간 t 동안의 상대각 $\theta = 360^\circ\, t/S$에 대해 $a = 1/\cos\theta$.

(2) 역행의 각속도와 유의 조건 (원 궤도·같은 평면)

지구(반지름 1, 각속도 ω₁)와 행성(반지름 a, ω₂)의 일심 경도 차가 θ일 때, 지구에서 본 행성 방향의 회전율은

$$\dot\lambda = \frac{a^2\omega_2 - a(\omega_1+\omega_2)\cos\theta + \omega_1}{1 + a^2 - 2a\cos\theta}$$

충(θ = 0)에서 $\dot\lambda = \dfrac{a\omega_2 - \omega_1}{a-1}$ — 외행성이면 음수(역행). 케플러 제3법칙 ω ∝ a−3/2를 넣으면 유($\dot\lambda=0$)의 조건은

$$\cos\theta_{\text{유}} = \frac{\sqrt{a}}{a - \sqrt{a} + 1}$$

역행 기간 ≈ $2\theta_{\text{유}} S/360^\circ$. 화성: θ ≈ 16.8°, 약 73일 · 목성: θ ≈ 54.4°, 약 121일 · 금성: θ ≈ 13.0°, 약 42일.

(3) 위상과 밝기

위상각 i(태양–행성–지구의 각)에 대해 밝게 보이는 비율 $k = (1+\cos i)/2$. 겉보기 밝기는 대략 $k/(r^2\Delta^2)$에 비례한다(r: 태양 거리, Δ: 지구 거리). 금성은 내합과 최대 이각 사이(이각 약 39°)에서 가장 밝다.

(4) 케플러 방정식과 활력 방정식

$$M = \frac{2\pi}{P}(t-\tau) = E - e\sin E,\qquad \tan\frac{\nu}{2} = \sqrt{\frac{1+e}{1-e}}\tan\frac{E}{2},\qquad r = a(1-e\cos E)$$ $$v^2 = GM\left(\frac{2}{r} - \frac{1}{a}\right) \quad\Rightarrow\quad v_c = \sqrt{GM/r},\;\; v_{\text{esc}} = \sqrt{2}\,v_c$$

태양계에서는 $\sqrt{GM_\odot/1\,\text{AU}} = 29.78$ km/s 를 기억하면 편리하다. 궤도는 6요소(a, e, i, Ω, ω, τ)로 정해진다.

예제 (올림피아드형)핼리 혜성(a = 17.8 AU, e = 0.967)의 근일점 속력과 원일점 속력은?
풀이$v_q = 29.78\sqrt{\dfrac{1+e}{a(1-e)}} = 29.78\sqrt{\dfrac{1.967}{17.8\times0.033}} = 29.78\times1.830 \approx 54.5$ km/s
$v_Q = v_q\dfrac{1-e}{1+e} = 54.5\times\dfrac{0.033}{1.967} \approx 0.91$ km/s. 주기 $P = 17.8^{1.5} \approx 75$년.

Ⅴ. 실전: 밤하늘에서 천구 떠올리기

1. 천구의 기본선 찾기

  1. 방위 정하기 → 북극성 찾기: 북두칠성 국자 끝 두 별(메라크 → 두베) 간격의 약 5배 연장. 또는 카시오페이아자리 W에서.
  2. 천구 북극: 북극성 바로 옆(0.7°). 고도 = 위도.
  3. 자오선: 북점 → 북극성 → 천정 → 남점.
  4. 천구의 적도: 동점·서점을 지나고 남쪽에서 고도 90° − φ(서울 ≈ 52.5°)인 점을 지나는 큰 원. 오리온 삼태성의 민타카(δ = −0.3°), 처녀자리 포리마(δ = −1.4°), 물병자리 사달멜리크(δ = −0.3°)가 거의 적도 위에 있다.
  5. 황도: 황도 12궁 별자리(레굴루스, 스피카, 안타레스, 알데바란 근처)를 잇는 선. 달과 행성이 이 근처에 있다.
  6. 춘분점: 페가수스 사각형의 동쪽 변(알페라츠 → 알게니브)을 같은 길이만큼 남쪽으로 연장한 근처 (물고기자리).

2. 항성시로 적경 읽기

지금 자오선을 지나는 별의 적경 = 항성시. 자오선에서 동쪽으로 15°씩 갈 때마다 적경이 1h 커지고, 서쪽으로는 작아진다(적위 δ인 곳에서는 실제 간격이 15° × cos δ). 예를 들어 시리우스(6h 45m)가 남중하면 LST ≈ 6h 45m이고, 그 순간 동쪽 지평선 근처에는 적경 약 12h 45m인 별들(처녀자리)이 떠오르고 있다(천구의 적도 위의 점은 남중 6시간 전에 뜬다).

    내행성과 외행성

    내행성(수성·금성)은 지구 궤도 안쪽, 외행성(화성~해왕성)은 바깥쪽에서 공전한다. 지구에서 볼 때 태양–지구–행성이 이루는 각을 이각(離角)이라 한다.

    내행성의 위치 관계

    • 내합: 태양–내행성–지구 순으로 일직선. 지구와 가장 가깝고 그믐달처럼 가늘게(관측 거의 불가) 보이며, 이 무렵 역행한다.
    • 외합: 내행성–태양–지구 순. 가장 멀고 보름달 모양이지만 태양에 가려 보이지 않는다.
    • 최대 이각: 지구에서 그은 시선이 궤도에 접할 때(∠태양–행성–지구 = 90°). 반달 모양. 수성 약 18°~28°, 금성 약 46°~47°.
    • 동방 최대 이각: 태양의 동쪽 → 초저녁 서쪽 하늘 / 서방 최대 이각: 태양의 서쪽 → 새벽 동쪽 하늘
    순서: 내합 → 서방 최대 이각 → 외합 → 동방 최대 이각 → 내합

    외행성의 위치 관계

    • 충: 태양–지구–외행성 순. 지구와 가장 가깝고 가장 밝으며 자정에 남중 → 밤새 보인다. 이 무렵 역행한다.
    • 합: 외행성–태양–지구 순. 태양과 함께 뜨고 져서 보이지 않는다.
    • 동구(이각 90°, 태양의 동쪽): 해 질 무렵 남중 / 서구(태양의 서쪽): 해 뜰 무렵 남중
    순서: 충 → 동구 → 합 → 서구 → 충

    겉보기 운동

    별자리를 배경으로 행성이 서→동으로 움직이면 순행, 동→서로 움직이면 역행, 방향이 바뀌며 잠시 멈춘 듯 보이면 유(留)라 한다. 역행은 지구가 행성을 추월할 때(외행성) 또는 내행성이 지구를 추월할 때 상대적인 시선 방향 변화로 생긴다.

    회합 주기

    행성이 같은 위치 관계(예: 충 → 다음 충)로 돌아오는 데 걸리는 시간 S. 공전 주기 P, 지구의 공전 주기 E(=1년)일 때

    내행성: 1/S = 1/P − 1/E    외행성: 1/S = 1/E − 1/P

    각속도의 차이(ω빠른 − ω느린)로 한 바퀴(360°)를 따라잡는 시간이라고 생각하면 바로 유도된다.

    심화: 역행의 각속도와 기간 (원 궤도) 충에서 지구와 행성의 공전 속도는 시선에 수직이므로, 상대 속도 v⊕ − vP 를 거리 (a − 1)로 나눈 값이 겉보기 각속도이다.
    ω역행 = (v⊕ − vP)/(a − 1) = (2π/E)·(1 − a−1/2)/(a − 1) [rad/일, a는 AU]
    화성(a = 1.524)이면 약 0.36°/일, 목성(5.20)이면 약 0.13°/일.
    유의 조건: 지구(반지름 1, 각속도 ω₁)와 행성(반지름 a, 각속도 ω₂)의 일심 경도 차를 θ라 하면 시선 방향의 회전율이 0인 조건은 a²ω₂ − a(ω₁ + ω₂) cos θ + ω₁ = 0. 케플러 제3법칙(ω ∝ a−3/2)을 넣으면
    cos θ유 = √a / (a − √a + 1)
    역행 기간 ≈ 2θ유·S/360°. 화성: θ유 ≈ 16.8°, S = 780일 → 약 73일. 금성: θ유 ≈ 13.0°, S = 584일 → 약 42일. (실제 궤도는 타원이라 해마다 조금씩 다르다. ‘다가오는 현상’ 목록에서 실제 유의 날짜를 확인해 보자.)
    심화: 내행성의 궤도 반지름 구하기 (코페르니쿠스) 최대 이각 Emax일 때 ∠태양–행성–지구 = 90° 이므로 a = sin Emax (AU). 금성의 최대 이각 46.3°이면 a ≈ 0.72 AU.
    외행성은 충에서 구까지 걸린 시간 t로 상대 각 θ = 360°·t/S 를 구하고 a = 1/cos θ 로 구한다.
    심화: 금성의 위상과 밝기 금성은 내합 근처에서 가장 크게(약 60″) 보이지만 가늘다. 밝기 ∝ (조명된 면적)/(거리²) 이므로 최대 밝기는 내합과 최대 이각 사이, 이각 약 39°(내합 전후 약 36일)일 때 나타난다(등급 약 −4.6).
    갈릴레이가 관측한 금성의 보름달 모양 위상과 크기 변화는 금성이 태양 둘레를 돈다는 증거였다. 프톨레마이오스 체계에서는 금성이 항상 태양보다 가까워 초승달~반달 모양만 보여야 한다.
